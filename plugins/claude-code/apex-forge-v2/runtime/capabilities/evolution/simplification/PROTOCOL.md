# Simplification

## Purpose

Remove unused, duplicate, obsolete, or speculative complexity with evidence.

## Method

1. Find candidates and their real production consumers.
2. Classify delete, deprecate, keep, or product decision.
3. Define deletion scope, risk, rollback, and regression checks.
4. Measure actual savings after verified removal.

## Output

Produce `simplification-evidence` with candidates, consumer evidence, deletion
plan, risk, verification, estimated and actual savings, and decision.
