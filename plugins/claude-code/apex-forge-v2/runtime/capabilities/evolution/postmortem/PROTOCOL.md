# Postmortem

## Purpose

Turn an escaped defect or failed control into a verified prevention mechanism.

## Method

1. Establish impact, timeline, detection gap, and root causes.
2. Identify failed controls and contributing assumptions.
3. Route corrective actions to test, gate, invariant, review rule, or manual control.
4. Verify the new control against the original failure.

## Output

Produce `postmortem-evidence` with impact, timeline, root causes, failed controls,
corrective actions, control candidates, owners, and verification.
