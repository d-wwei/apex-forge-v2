# Browser QA

## Purpose

Validate web behavior through the real user-visible URL and browser surface.

## Method

1. Confirm the exact URL, server, viewport, and browser provider.
2. Execute declared user flows.
3. Capture screenshots, console errors, network errors, and accessibility findings.
4. Reject substitute servers or screenshots that do not match the target flow.

## Output

Produce `browser-qa-evidence` with URL, provider, viewport, flows, screenshots,
console/network evidence, accessibility findings, and results.
