# Design To Code

## Purpose

Implement an approved design specification without silent substitution.

## Method

1. Validate the design and implementation specification.
2. Map each component to existing, composed, or new code.
3. Implement against the binding specification.
4. Complete the fidelity and acceptance checklist.

## Output

Produce `design-to-code-evidence` with design reference, implementation spec,
component map, changed files, checklist, and fidelity findings.
