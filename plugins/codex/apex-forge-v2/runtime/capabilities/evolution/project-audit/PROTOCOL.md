# Project Audit

## Purpose

Audit actual project behavior against explicit design commitments.

## Method

1. Mine and classify commitments.
2. Build executable checks and review the checks themselves.
3. Run the audit and inspect distribution, missing evidence, and contradictions.
4. Produce findings and release posture without converting unknowns into PASS.

## Output

Produce `project-audit-evidence` with commitments, checks, findings, coverage,
confidence, unverified items, score, and release posture.
