# Frontend Design

## Purpose

Create an intentional, implementable visual and interaction specification.

## Method

1. Establish product context, audience, and experience goals.
2. Define information architecture and responsive layout.
3. Explore and select a visual direction.
4. Produce tokens, component behavior, interaction states, and acceptance.

## Output

Produce `frontend-design-evidence` with brief, layout, selected direction,
tokens, responsive rules, interaction states, and acceptance.
