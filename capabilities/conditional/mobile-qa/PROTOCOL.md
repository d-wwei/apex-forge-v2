# Mobile QA

## Purpose

Validate iOS or Android behavior on a declared simulator, emulator, or device.

## Method

1. Detect available platform tools without installing them.
2. Select a declared device and OS version.
3. Install, launch, execute flows, and capture logs and media.
4. Clean up the device state and report unavailable platforms explicitly.

## Output

Produce `mobile-qa-evidence` with platform, device, OS, app artifact, flows,
screenshots or video, crashes, logs, and cleanup.
