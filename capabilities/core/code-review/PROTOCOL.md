# Code Review

## Purpose

Review the current candidate for correctness, regressions, and merge readiness.

## Method

1. Bind the review to the current candidate digest.
2. Inspect requirements, diff, tests, error paths, concurrency, and state consistency.
3. Classify findings by severity and blocking status.
4. State residual risks and merge posture.

## Output

Produce `code-review-evidence` with candidate identity, findings, test gaps,
residual risks, and merge posture.
