# Engineering Spec

## Purpose

Turn an underspecified engineering request into a bounded implementation contract.

## Method

1. State the objective and observable acceptance criteria.
2. Separate in-scope, out-of-scope, assumptions, and open questions.
3. Name affected contracts, files, compatibility constraints, and verification.
4. Block implementation when a material decision is unresolved.

## Output

Produce `engineering-spec-evidence` with objective, scope, acceptance,
assumptions, open questions, and verification plan.
