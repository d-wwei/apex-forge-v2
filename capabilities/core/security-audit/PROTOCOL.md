# Security Audit

## Purpose

Inspect security-sensitive changes with evidence-backed findings and low noise.

## Method

1. Define threat surface and sensitive assets.
2. Check secrets, dependencies, permissions, input boundaries, auth, and CI/CD.
3. Bind each finding to a location, evidence, severity, and remediation.
4. Keep uncertain concerns visible without presenting them as confirmed.

## Output

Produce `security-audit-evidence` with threat model, CWE-tagged findings,
scan evidence, residual risks, and merge posture.
