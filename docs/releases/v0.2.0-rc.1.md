## Highlights

### Agent Plugin product shape

- Six shared workflows rendered as native Codex and Claude Code Skills.
- Natural-language plan, execute, review, ship, status and recovery entrypoints.
- Interactive Mode uses the current Host Agent instead of launching a nested
  Agent by default.
- Factory Mode remains available for isolated, parallel, background or
  resumable work.

### Safe workspace and immutable delivery

- Interactive code changes happen only inside an action-owned workspace.
- Secrets, binaries, symlinks, deletes and out-of-scope changes fail closed.
- Verification, semantic review, approval and merge bind to one immutable
  `candidate_digest`.
- Candidate mutation invalidates downstream evidence automatically.

### Durable Kernel

- Transaction WAL, revision CAS, idempotency, lease and fencing.
- Crash recovery for interrupted transactions, stale locks and orphan
  workspaces.
- Event replay and reconcile verify the materialized project state.
- Typed cognitive evidence prevents generic summaries or shell exits from
  impersonating semantic work.

### Governed parallel verification

- Cross-repository parallelism with same-repository serialization.
- Hard limit of three formal benchmark workers.
- TERM/KILL process-tree cleanup and guard-token orphan recovery.
- Disk headroom, workspace growth and output-size circuit breakers.
- Durable Codex rollout usage evidence survives SSE disconnects.

## Installation

### Codex

```bash
git clone https://github.com/d-wwei/apex-forge-v2.git
cd apex-forge-v2
npm ci
npm run build:plugin

codex plugin marketplace add .
codex plugin add apex-forge-v2@apex-forge-local
```

Start a new Codex task after installation so the updated Skills are loaded.

### Claude Code

```bash
claude plugin marketplace add ./plugins/claude-code
claude plugin install apex-forge-v2@apex-forge-local --scope user
```

## Example

```text
Use Apex Forge to implement this requirement:
add bounded retries to the import worker and protect the regression with tests.
```

Apex Forge will create or resume durable project state, select Interactive or
Factory Mode, bind evidence to a Candidate, verify the patch, perform semantic
review and close the run only after the Kernel confirms durable completion.

## Known Boundaries

- This is a release candidate and is published as a GitHub prerelease.
- Complex multi-step, interrupted, review-defect and parallel scenarios use
  more wall time and tokens than Apex Forge V1, although completion, safety,
  evidence and durability pass the release gates.
- DeepSeek is validated behind the generic ModelProvider / WorkerExecutor
  boundary; this release does not claim live DeepSeek endpoint validation.
- MCP remains deferred until a real remote-control or cross-machine trigger
  exists.

## Upgrade Notes

Existing `.apex-v2` project state remains the source of truth. Plugin
installation, update, rollback and uninstall were verified not to mutate an
active Apex project.
